## Why Struct Frame

<CardGrid>
  <Card title="Zero-copy C/C++" icon="rocket">
    Uses packed structs that map directly to memory. No encoding or decoding step required.
  </Card>
  <Card title="Flexible framing" icon="setting">
    Multiple frame profiles for different scenarios, from zero-overhead trusted links to robust multi-node networks.
  </Card>
  <Card title="Nested messages & arrays" icon="list-format">
    Unlike Mavlink, supports complex message structures with nested messages and variable-length packing for arrays.
  </Card>
  <Card title="Cross-platform" icon="puzzle">
    Generate code for embedded C, server Python, and frontend TypeScript from a single proto definition.
  </Card>
</CardGrid>

## Installation

```bash
pip install struct-frame
```

## Quick Start

Create a schema, `status.sf`:

```proto
package example;

message Status {
  option msgid = 1;
  uint32 id = 1;
  float value = 2;
}
```

Generate code:

```bash
# Python and C into generated/py and generated/c
struct-frame status.sf --lang py,c

# Every language, under build/gen/<lang>
struct-frame status.sf --lang all --out build/gen
```

## Quick Language Reference

<Tabs>
  <TabItem label="C++">
  ```cpp no-compile
  #include "example.structframe.hpp"
  #include "frame_profiles.hpp"

  structframe::example::Status msg{};
  msg.id = 42;
  msg.value = 3.14f;

  // Fixed messages are packed structs; the writer frames them with a checksum
  uint8_t buffer[64];
  structframe::ProfileStandardWriter writer(buffer, sizeof(buffer));
  writer.write(msg);
  ```
  </TabItem>
  <TabItem label="Python">
  ```python no-compile
  from structframe.example import Status

  msg = Status(id=42, value=3.14)
  data = msg.serialize()
  ```
  </TabItem>
  <TabItem label="TypeScript">
  ```typescript no-compile
  import { Status } from './example.structframe';

  const msg = new Status({ id: 42, value: 3.14 });
  const data = msg.serialize();
  ```
  </TabItem>
  <TabItem label="C">
  ```c no-compile
  #include "example.structframe.h"

  ExampleStatus msg = { .id = 42, .value = 3.14f };

  uint8_t buffer[64];
  buffer_writer_t writer;
  buffer_writer_init(&writer, &PROFILE_STANDARD_CONFIG, buffer, sizeof(buffer));
  ExampleStatus_write(&writer, &msg);   /* frame + checksum */
  ```
  </TabItem>
</Tabs>
