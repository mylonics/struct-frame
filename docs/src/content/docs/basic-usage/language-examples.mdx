This page shows the same steps in every language: create a message, write it into a frame, feed received bytes to a reader, and decode the frames that come out.

## Proto Definition

Examples use this schema (`example.sf`):

```proto
package example;

message Status {
  option msgid = 1;
  uint32 id = 1;
  float value = 2;
}
```

Generate code for every language under `generated/<lang>`:

```bash
struct-frame example.sf --lang all --out generated
```

## Using Frame Profiles

Frame profiles provide complete framing and parsing functionality. This is the **recommended approach** for most applications.

:::note[Generated names]
Only C prefixes the package name onto type names (`ExampleStatus`). C++ puts types in `structframe::example`, C# in `StructFrame.Example`, Rust in the `example` module, and Python, TypeScript and JavaScript use the bare name (`Status`) inside the package's module. Fields use each language's convention (`snake_case` in C, C++, Python and Rust; `camelCase` in TypeScript and JavaScript; `PascalCase` in C#).
:::

:::tip[Why the readers take a message-info function]
The checksum of every CRC profile (Standard, Bulk, Network) includes two per-message "magic" bytes derived from the message layout, and the minimal profiles (Sensor, IPC) have no length field, so the reader needs each message's size. It gets both from the generated `get_message_info` function, so pass it to the reader; without it no real frame is accepted.
:::

:::tip[Draining a reader]
Every reader has `try_next` (or an equivalent), which keeps returning results until the buffered data is used up: valid frames, and invalid ones for corrupt frames and skipped noise. Loop on it and check `valid`. A loop that stops at the first invalid result stops at the first corrupt frame.
:::

### Python with Profiles

```python
# The --py-path directory must be on sys.path
import sys
sys.path.insert(0, 'generated/py')

from structframe.frame_profiles import BufferWriter, AccumulatingReader, PROFILE_STANDARD_CONFIG
from structframe.example import Status, get_message_info, decode_message

# Create and encode a message with a frame profile
msg = Status(id=42, value=3.14)
writer = BufferWriter(PROFILE_STANDARD_CONFIG, 1024)
writer.write(msg)
frame_data = writer.data()

# Parse received frames
reader = AccumulatingReader(PROFILE_STANDARD_CONFIG, get_message_info=get_message_info)
reader.add_data(frame_data)

while (frame := reader.try_next()) is not None:
    decoded = decode_message(frame)   # None for corrupt frames and other packages' IDs
    if isinstance(decoded, Status):
        print(f"ID: {decoded.id}, Value: {decoded.value}")
```

`Status.deserialize(frame)` decodes one known type directly; `decode_message` picks the class from the frame's message ID.

### TypeScript with Profiles

```typescript
import { Status, getMessageInfo, decodeMessage } from './generated/ts/example.structframe';
import { BufferWriter, AccumulatingReader, ProfileStandardConfig } from './generated/ts/frame-profiles';

// Create and encode a message with a frame profile
const msg = new Status({ id: 42, value: 3.14 });
const writer = new BufferWriter(ProfileStandardConfig, 1024);
writer.write(msg);
const frameData = writer.data();

// Parse received frames
const reader = new AccumulatingReader(ProfileStandardConfig, getMessageInfo);
reader.addData(frameData);

let frame;
while ((frame = reader.tryNext()) !== null) {
    const decoded = decodeMessage(frame);   // undefined for corrupt frames and other IDs
    if (decoded instanceof Status) {
        console.log(`ID: ${decoded.id}, Value: ${decoded.value}`);
    }
}
```

The output folder's `index.ts` re-exports the runtime and one namespace per package, so `import { example, BufferWriter } from './generated/ts'` also works (`new example.Status(...)`). Compare `frame.msgId` with `Status.MSG_ID` to dispatch by hand.

### C++ with Profiles

```cpp
#include <iostream>
#include "example.structframe.hpp"
#include "frame_profiles.hpp"

using namespace structframe;

// Create a message
example::Status msg{};
msg.id = 42;
msg.value = 3.14f;

// Encode with a frame profile
uint8_t buffer[1024];
ProfileStandardWriter writer(buffer, sizeof(buffer));
writer.write(msg);

// Parse received frames. The Profile*AccumulatingReader aliases take the
// generated message-info function.
ProfileStandardAccumulatingReader reader(example::get_message_info);
reader.add_data(buffer, writer.size());

FrameMsgInfo result;
while (reader.try_next(result)) {
    if (result.valid && result.msg_id == example::Status::MSG_ID) {
        example::Status decoded;
        decoded.deserialize(result);
        std::cout << "ID: " << decoded.id << ", Value: " << decoded.value << std::endl;
    }
}
```

`ProfileReader<ProfileBulkConfig, 4096>` gives a reader with a different buffer size. With several packages, include `structframe_all.hpp` and pass `structframe::get_message_info`, which knows every package.

### C with Profiles

```c
#include <stdio.h>
#include "example.structframe.h"   /* includes frame_profiles.h */

/* Create a message */
ExampleStatus msg = {.id = 42, .value = 3.14f};

/* Encode with a frame profile. ExampleStatus_write fills in the message ID,
 * package ID and checksum magic bytes. */
uint8_t buffer[1024];
buffer_writer_t writer;
buffer_writer_init(&writer, &PROFILE_STANDARD_CONFIG, buffer, sizeof(buffer));
ExampleStatus_write(&writer, &msg);

/* Parse received frames */
uint8_t internal[1024];
accumulating_reader_t reader;
accumulating_reader_init(&reader, &PROFILE_STANDARD_CONFIG, internal, sizeof(internal),
                         example_get_message_info);
accumulating_reader_add_data(&reader, buffer, buffer_writer_size(&writer));

frame_msg_info_t result;
while (accumulating_reader_try_next(&reader, &result)) {
    if (result.valid && result.msg_id == EXAMPLE_STATUS_MSG_ID) {
        ExampleStatus decoded;
        ExampleStatus_deserialize(result.msg_data, result.msg_len, &decoded);
        printf("ID: %u, Value: %f\n", (unsigned)decoded.id, decoded.value);
    }
}
```

`ExampleStatus_write_ext(&writer, &msg, seq, sys_id, comp_id)` sets the sequence number and routing IDs on the profiles that carry them. With several packages, include `structframe_all.h` and pass `structframe_all_get_message_info` to the reader.

### C# with Profiles

```csharp
using StructFrame;
using StructFrame.Framing;
using StructFrame.Profiles;
using StructFrame.Example;

// Create a message
var msg = new Status { Id = 42, Value = 3.14f };

// Encode with a frame profile
var writer = new BufferWriter<StandardProfile>(1024);
writer.Write(msg);
byte[] frameData = writer.GetData();

// Parse received frames
var reader = new AccumulatingReader<StandardProfile>(getMessageInfo: MessageDefinitions.GetMessageInfo);
reader.AddData(frameData);

while (reader.TryNext(out var result))
{
    if (result.Valid && MessageDefinitions.Deserialize(result) is Status decoded)
    {
        Console.WriteLine($"ID: {decoded.Id}, Value: {decoded.Value}");
    }
}
```

`Status.Deserialize(result)` decodes one known type directly.

### Rust with Profiles

```rust
use struct_frame_sdk::example::Status;
use struct_frame_sdk::prelude::*;

// Create and encode a message with a frame profile
let msg = Status { id: 42, value: 3.14 };
let mut writer = BufferWriter::new(PROFILE_STANDARD_CONFIG, 1024);
writer.write(&msg);

// Parse received frames. with_message_info stores the lookup function, so frames()
// and next_frame() need no argument.
let mut reader = AccumulatingReader::with_message_info(PROFILE_STANDARD_CONFIG, 4096,
                                                       struct_frame_sdk::get_message_info);
reader.add_data(writer.data());

for frame in reader.frames().filter(|f| f.valid) {
    if frame.msg_id == Status::MSG_ID {
        if let Some(decoded) = Status::deserialize(&frame) {
            println!("ID: {}, Value: {}", decoded.id, decoded.value);
        }
    }
}
```

`writer.write_ext(&msg, seq, sys_id, comp_id)` sets the sequence number and routing IDs on the profiles that carry them.

## Communication Examples

### Serial Communication (Python)

```python
import sys
import serial
sys.path.insert(0, 'generated/py')

from structframe.example import Status, get_message_info
from structframe.frame_profiles import AccumulatingReader, PROFILE_STANDARD_CONFIG

ser = serial.Serial('/dev/ttyUSB0', 115200)
reader = AccumulatingReader(PROFILE_STANDARD_CONFIG, get_message_info=get_message_info)

while True:
    reader.add_data(ser.read(ser.in_waiting or 1))
    while (frame := reader.try_next()) is not None:
        if frame.valid and frame.msg_id == Status.MSG_ID:
            msg = Status.deserialize(frame)
            print(f"Received: ID={msg.id}, Value={msg.value}")
```

### Streaming Parser (C++)

```cpp no-compile
#include "example.structframe.hpp"
#include "frame_profiles.hpp"

using namespace structframe;

// Byte-by-byte streaming parser for UART/serial.
ProfileStandardAccumulatingReader reader(example::get_message_info);

void on_byte_received(uint8_t byte) {
    if (auto result = reader.push_byte(byte)) {
        example::Status msg;
        msg.deserialize(result);
        std::cout << "ID: " << msg.id << std::endl;
    }
}
```

### TCP Socket (TypeScript)

```typescript
import * as net from 'net';
import { Status, getMessageInfo } from './generated/ts/example.structframe';
import { AccumulatingReader, ProfileStandardConfig } from './generated/ts/frame-profiles';

const client = net.createConnection({ port: 8080 });
const reader = new AccumulatingReader(ProfileStandardConfig, getMessageInfo);

client.on('data', (data: Buffer) => {
    reader.addData(data);
    let frame;
    while ((frame = reader.tryNext()) !== null) {
        if (frame.valid && frame.msgId === Status.MSG_ID) {
            const msg = Status.deserialize(frame);
            console.log(`ID: ${msg.id}, Value: ${msg.value}`);
        }
    }
});
```

### WebSocket (JavaScript)

```javascript

            const msg = Status.deserialize(frame);
            console.log(`ID: ${msg.id}, Value: ${msg.value}`);
        }
    }
});
```

## Frame Profiles

Different profiles for different use cases:

- **ProfileStandard**: General purpose (Basic header + Default payload)
- **ProfileSensor**: Low-bandwidth sensors (Tiny header + Minimal payload)
- **ProfileIPC**: Trusted inter-process (No header + Minimal payload)
- **ProfileBulk**: Large data transfers (Basic header + Extended payload)
- **ProfileNetwork**: Multi-system networks (Basic header + Extended Multi-System Stream payload)

All profiles support the same API: pass a different profile configuration (`PROFILE_SENSOR_CONFIG`, `ProfileSensorConfig`, `StandardProfile` → `SensorProfile`, and so on) to the same writer and reader types. C++ also offers aliases such as `ProfileSensorWriter` and `ProfileSensorAccumulatingReader`.

## Key Takeaways

1. **Consistent API**: Every language has a writer that frames a message (`write`), a reader that takes the generated message-info function, and `deserialize` (case varies by language convention).
2. **Frame Profiles**: Use a profile configuration with the BufferWriter and AccumulatingReader types for complete framing and parsing.
3. **Drain with `try_next`**: It returns every frame and every corrupt-frame event; check `valid`.
4. **Decode by ID**: Python `decode_message`, TypeScript/JavaScript `decodeMessage` and C# `MessageDefinitions.Deserialize` return the typed message for a frame; elsewhere compare `msg_id` with the type's `MSG_ID`.
5. **Variable Messages**: Transparent handling - same API for fixed and variable-length messages.
