This page shows how to use generated code in each language with the standardized serialize/deserialize API.

## Proto Definition

Examples use this proto file:

```proto
package example;

message Status {
  option msgid = 1;
  uint32 id = 1;
  float value = 2;
}
```

Generate code:
```bash
python -m struct_frame status.proto --build_c --build_cpp --build_ts --build_py --build_js --build_csharp --build_rust
```

## Using Frame Profiles

Frame profiles provide complete framing and parsing functionality. This is the **recommended approach** for most applications.

:::note[Generated names]
Only C prefixes the package name onto type names (`ExampleStatus`). C++ puts types in `structframe::example`, C# in `StructFrame.Example`, Rust in the `example` module, and Python, TypeScript and JavaScript use the bare name (`Status`). Fields use each language's convention (`snake_case` in C, C++, Python and Rust; `camelCase` in TypeScript and JavaScript; `PascalCase` in C#).
:::

:::tip[Why the readers take a message-info function]
The checksum of every CRC profile (Standard, Bulk, Network) includes two per-message "magic" bytes derived from the message layout. The reader gets them from the generated `get_message_info` function, so pass it to the reader; without it every real frame fails its checksum.
:::

### Python with Profiles

```python
# Add py_path to sys.path before importing
import sys
sys.path.insert(0, 'generated/')  # py_path

from frame_profiles import BufferWriter, AccumulatingReader, PROFILE_STANDARD_CONFIG
from struct_frame.generated.example import Status, get_message_info

# Create and encode a message with a frame profile
msg = Status(id=42, value=3.14)
writer = BufferWriter(PROFILE_STANDARD_CONFIG, 1024)
writer.write(msg)
frame_data = writer.data()

# Parse received frames
reader = AccumulatingReader(PROFILE_STANDARD_CONFIG, get_message_info=get_message_info)
reader.add_data(frame_data)

result = reader.next()
if result.valid:
    decoded = Status.deserialize(result.msg_data)
    print(f"ID: {decoded.id}, Value: {decoded.value}")
```

### TypeScript with Profiles

```typescript
import { Status, getMessageInfo } from './generated/example.structframe';
import { BufferWriter, AccumulatingReader, ProfileStandardConfig } from './generated/frame-profiles';

// Create and encode a message with a frame profile

const writer = new BufferWriter(ProfileStandardConfig, 1024);

// Parse received frames
const reader = new AccumulatingReader(ProfileStandardConfig, getMessageInfo);
reader.addData(frameData);

    const decoded = Status.deserialize(result);  // pass the frame directly
    console.log(`ID: ${decoded.id}, Value: ${decoded.value}`);
}
```

### C++ with Profiles

```cpp
#include "example.structframe.hpp"
#include "frame_profiles.hpp"

using namespace structframe;

// Create a message
example::Status msg;
msg.id = 42;
msg.value = 3.14f;

// Encode with a frame profile
uint8_t buffer[1024];
ProfileStandardWriter writer(buffer, sizeof(buffer));
writer.write(msg);

// Parse received frames. CRC profiles need the message-info callback, so use the
// explicit template form rather than the ProfileStandardAccumulatingReader alias.
AccumulatingReader<ProfileStandardConfig, 1024, decltype(&example::get_message_info)>
    reader(example::get_message_info);
reader.add_data(buffer, writer.size());

auto result = reader.next();
if (result.valid) {
    example::Status decoded;
    decoded.deserialize(result.msg_data, result.msg_len);
    std::cout << "ID: " << decoded.id << ", Value: " << decoded.value << std::endl;
}
```

### C with Profiles

```c
#include "frame_profiles.h"
#include "example.structframe.h"

/* Create a message */
ExampleStatus msg = {.id = 42, .value = 3.14f};

/* Encode with a frame profile */
uint8_t buffer[1024];
buffer_writer_t writer;
buffer_writer_init(&writer, &PROFILE_STANDARD_CONFIG, buffer, sizeof(buffer));
buffer_writer_write(&writer, EXAMPLE_STATUS_MSG_ID, (const uint8_t*)&msg, sizeof(msg),
                    0, 0, 0, 0, EXAMPLE_STATUS_MAGIC1, EXAMPLE_STATUS_MAGIC2);

/* Parse received frames */
uint8_t internal[1024];
accumulating_reader_t reader;
accumulating_reader_init(&reader, &PROFILE_STANDARD_CONFIG, internal, sizeof(internal),
                         example_get_message_info);
accumulating_reader_add_data(&reader, buffer, buffer_writer_size(&writer));

frame_msg_info_t result = accumulating_reader_next(&reader);
if (result.valid) {
    ExampleStatus decoded;
    ExampleStatus_deserialize(result.msg_data, result.msg_len, &decoded);
    printf("ID: %u, Value: %f\n", (unsigned)decoded.id, decoded.value);
}
```

### C# with Profiles

```csharp
using StructFrame;
using StructFrame.Framing;
using StructFrame.Profiles;
using StructFrame.Example;

// Create a message
var msg = new Status { Id = 42, Value = 3.14f };

// Encode with a frame profile
var writer = new BufferWriter<StandardProfile>();
writer.SetBuffer(new byte[1024]);
writer.Write(msg);
byte[] frameData = writer.GetData();

// Parse received frames
var reader = new AccumulatingReader<StandardProfile>(getMessageInfo: MessageDefinitions.GetMessageInfo);
reader.AddData(frameData);

while (reader.TryNext(out var result))
{
    var decoded = Status.Deserialize(result.MsgData!.AsSpan(result.MsgDataOffset, result.MsgLen));
    Console.WriteLine($"ID: {decoded.Id}, Value: {decoded.Value}");
}
```

### Rust with Profiles

```rust
use struct_frame_sdk::example::Status;
use struct_frame_sdk::prelude::*;

// Create and encode a message with a frame profile
let msg = Status { id: 42, value: 3.14 };
let mut buffer = [0u8; 1024];
let written = encode_message_crc(&PROFILE_STANDARD_CONFIG, &mut buffer, &msg, 0);
let frame_data = &buffer[..written];

// Parse received frames
let mut reader = AccumulatingReader::new(PROFILE_STANDARD_CONFIG, 4096);
reader.add_data(frame_data);

let get_info = struct_frame_sdk::get_message_info;
while let Some(info) = reader.next(&get_info) {
    if info.valid {
        if let Some(decoded) = Status::unpack(&info.msg_data) {
            println!("ID: {}, Value: {}", decoded.id, decoded.value);
        }
    }
}
```

## Communication Examples

### Serial Communication (Python)

```python
import sys
import serial
sys.path.insert(0, 'generated/')  # py_path

from struct_frame.generated.example import Status, get_message_info
from frame_profiles import AccumulatingReader, PROFILE_STANDARD_CONFIG

# Setup serial connection
ser = serial.Serial('/dev/ttyUSB0', 115200)
reader = AccumulatingReader(PROFILE_STANDARD_CONFIG, get_message_info=get_message_info)

while True:
    if ser.in_waiting:
        # Read available data
        data = ser.read(ser.in_waiting)
        reader.add_data(data)
        
        # Process all complete frames
        while True:
            result = reader.next()
            if not result.valid:
                break

            msg = Status.deserialize(result.msg_data)
            print(f"Received: ID={msg.id}, Value={msg.value}")
```

### Streaming Parser (C++)

```cpp
#include "example.structframe.hpp"
#include "frame_profiles.hpp"

using namespace structframe;

// Byte-by-byte streaming parser for UART/serial. CRC profiles need the
// message-info callback, so use the explicit template form.
AccumulatingReader<ProfileStandardConfig, 1024, decltype(&example::get_message_info)>
    reader(example::get_message_info);

void on_byte_received(uint8_t byte) {
    auto result = reader.push_byte(byte);
    if (result.valid) {
        example::Status msg;
        msg.deserialize(result.msg_data, result.msg_len);
        std::cout << "ID: " << msg.id << std::endl;
    }
}
```

### TCP Socket (TypeScript)

```typescript
import * as net from 'net';
import { Status, getMessageInfo } from './generated/example.structframe';
import { AccumulatingReader, ProfileStandardConfig } from './generated/frame-profiles';

const client = net.createConnection({ port: 8080 });
const reader = new AccumulatingReader(ProfileStandardConfig, getMessageInfo);

client.on('data', (data: Buffer) => {
    reader.addData(data);
    
    let result;
    while ((result = reader.next()) && result.valid) {
        const msg = Status.deserialize(result);
        console.log(`ID: ${msg.id}, Value: ${msg.value}`);
    }
});
```

### WebSocket (JavaScript)

```javascript
const { Status, getMessageInfo } = require('./generated/example.structframe');

const WebSocket = require('ws');

    let result;
    while ((result = reader.next()) && result.valid) {
        const msg = Status.deserialize(result);
        console.log(`ID: ${msg.id}, Value: ${msg.value}`);
    }
});
```

## Frame Profiles

Different profiles for different use cases:

- **ProfileStandard**: General purpose (Basic header + Default payload)
- **ProfileSensor**: Low-bandwidth sensors (Tiny header + Minimal payload)
- **ProfileIPC**: Trusted inter-process (No header + Minimal payload)
- **ProfileBulk**: Large data transfers (Basic header + Extended payload)
- **ProfileNetwork**: Multi-system networks (Basic header + Extended Multi-System Stream payload)

All profiles support the same API: pass a different profile configuration (`PROFILE_SENSOR_CONFIG`, `ProfileSensorConfig`, `StandardProfile` → `SensorProfile`, and so on) to the same writer and reader types. C++ also offers aliases such as `ProfileSensorWriter`.

## Key Takeaways

1. **Consistent API**: All languages use `serialize()` / `deserialize()` (case varies by language convention)
2. **Frame Profiles**: Use a profile configuration with the BufferWriter and AccumulatingReader types for complete framing and parsing
3. **FrameMsgInfo**: Pass frame parser results directly to `deserialize()` - no manual extraction needed
4. **Variable Messages**: Transparent handling - same API for fixed and variable-length messages
5. **Arrays & Nested Messages**: Automatically handled by serialize/deserialize
